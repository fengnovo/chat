# Web 关键流程 E2E Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Playwright 为 Web 端登录、聊天、文件面板/灯箱、知识库、管理员和长期记忆流程补充稳定的浏览器回归测试。

**Architecture:** E2E 运行真实 Next.js Web server，但通过 Playwright route mock 拦截 `/api/**`，不依赖后端基础设施。共享 fixture 处理认证与常用响应，各测试只定义自身页面需要的 API 数据；CI 使用独立 job 安装 Chromium 并上传失败报告。

**Tech Stack:** Node.js 22、pnpm 11.24.0、Next.js 16、Playwright Test、Chromium。

**Spec:** `docs/superpowers/specs/2026-09-22-web-e2e-design.md`

## Global Constraints

- 不依赖真实模型、数据库、Redis、对象存储或第三方 OAuth。
- 不修改生产 API 协议；mock 响应必须符合现有 Web API 类型和页面行为。
- E2E 使用稳定的可访问名称和业务文本，不依赖 CSS 类名或像素坐标。
- 失败时保留 Playwright report/trace；本地默认复用已经启动的 Web server。
